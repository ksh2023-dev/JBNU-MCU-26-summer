# GitHub 협업 규칙

1. main에서 직접 작업하지 않는다.
2. 작업 하나당 브랜치 하나를 만든다.
3. 작업 시작 전 반드시 pull하여 최신 main에서 브랜치를 만든다.
4. 작업이 끝나면 Pull Request를 만들고 카톡방에 알린다.
5. 최소 한 명이 24시간 이내 코멘트한 뒤 main에 병합한다.
6. 병합된 작업 브랜치는 삭제한다.
7. 충돌발생 시 상의해서 코드를 수정한다. 독단적으로 수정하지 않는다.
8. 커밋 메시지에는 변경 목적을 명확하게 적는다.
9. 브랜치명 형식:  frontend/기능_작업자 이름
10. README를 구체적으로 작성한다.
