# specialty_collector

전북대병원 교수 프로필 페이지에서 **전문진료분야**(데이터 계약 `specialties` 필드의 재료)를 수집한다.
임상 교수만 대상이며(기초 교수는 병원 프로필 페이지가 없어 대상 아님), 입력은 사진 수집기와 동일한
`data/input/professor_pages.json` (243명)를 사용한다.

## 실행

```bash
python scripts/specialty_collector/fetch_specialties.py
```

- 스크립트 상단 `LIMIT` 상수로 처리 인원을 제한할 수 있다 (기본 `None` = 전체 243명).
- 결과는 `data/output/specialties.json`에 저장된다.
- 요청 사이 `time.sleep(0.5)`로 서버 예절을 지키며, 병렬 요청은 하지 않는다.
- 요청 실패 시 1회 재시도 후에도 실패하면 `raw: None, specialties: []`로 기록하고 계속 진행한다(중단하지 않음).

## probe 결과 — 항목 위치·형식

프로필 페이지 3개(유희철·이창섭·김동찬) + 무작위 표본 8개, 총 11개 페이지의 실제 HTML을 확인해 결정했다.

- "전문진료분야"는 정적 HTML의 `<div class="infoBox ib1">` 블록에 들어 있다 (자바스크립트 렌더링 아님 → 표준 라이브러리 `urllib` + 정규식으로 파싱 가능).

```html
<div class="infoBox ib1">
    <div class="info-title icon">
        <strong class="tit"><i class="icon plusIcon" ...></i> 전문진료분야</strong>
    </div>
    <div class="info-con">
        <p class="conText"> 간담도, 췌장질환, 이식외과, 혈관외과, 간담췌질환 </p>
    </div>
</div>
```

- 확인한 페이지 전부에서 항목 구분자는 **쉼표(,)** 만 사용했다. 가운뎃점(·)은 실제로는 발견되지 않았지만
  지시서에 언급된 만큼 안전하게 쉼표·가운뎃점 둘 다 구분자로 처리하도록 구현했다.
- 항목 사이 공백이 페이지마다 제각각(없음/한 칸/두 칸)이라 분리 후 `strip()`으로 정리한다.
- "전문진료분야" 블록 자체가 없거나(예: 오신영), 있어도 내용이 공백뿐인 경우(예: 김지혜)가 있다
  → 이 경우 `raw: null, specialties: []`로 기록한다 (지어내지 않음 — 데이터 계약 0장 원칙 2).

## 괄호 처리 (LIMIT=10 실측 → 전체 실행 1차 결과 검수 중 발견)

전체 243명 1차 실행 결과를 검수하다가, 괄호 **안에도** 쉼표를 쓰는 사례가 다수 있는 것을 발견했다.

```
관절(어깨,무릎)통증
내분비질환(갑상선,부신,이상지질혈증,뇌하수체기능저하등)
척추 퇴행성 질환[경추 및 흉추 척수증, 요추 협착증, 추간판(디스크) 탈출증]
```

단순히 쉼표마다 자르면 `"관절(어깨"` / `"무릎)통증"`처럼 괄호가 깨진 항목이 생긴다. 이를 막기 위해
`split_specialties()`에서 괄호(`(`·`)`, `[`·`]`) 깊이를 세어, **깊이 0일 때의 구분자만** 항목 경계로
인정하도록 수정했다. 수정 후 전체 재실행 결과에서 괄호 개수 불일치(깨진 괄호) 항목은 0건이다.

## 출력 형식

```json
{
  "collectedAt": "2026-08-16",
  "specialties": {
    "유희철": {
      "raw": "간담도, 췌장질환, 이식외과, 혈관외과, 간담췌질환",
      "specialties": ["간담도", "췌장질환", "이식외과", "혈관외과", "간담췌질환"]
    }
  }
}
```

- `raw` — 페이지에서 추출한 원본 문자열 그대로 (공백 정리만 함). 값이 없으면 `null`.
- `specialties` — `raw`를 구분자로 나눈 배열. 검증은 `raw`와 대조해서 한다. 값이 없으면 `[]`.

## 최종 실행 결과 (243명, 2026-08-16)

- 수집(specialties가 1개 이상) 241명 / 빈 값(raw 없음) 2명 / 요청 실패 0명
